# Paletto

Paletto is your design kickstarter: it helps developers quickly launch a project with a beautiful, professional-looking theme—even if you don’t have a designer. Instantly generate color palettes, spacing, borders, and more, with live preview and ready-to-use code for your favorite UI framework (MUI, shadcn/ui, etc).

## What is Paletto?

Paletto is a friendly tool for developers to design and preview a custom theme for their next project. Whether you’re a solo developer or working without a dedicated designer, Paletto lets you generate a palette, adjust spacing and borders, and instantly see the results. Export your theme settings for frameworks like MUI or shadcn/ui, and use them right away.

## Features

- Palette generation (various strategies)
- Live design preview
- Tweak UI framework settings
- Export palette and framework configurations (MUI, shadcn/ui, etc)
- Test color combinations for accessibility (A11Y)
- Developer-friendly and accessible UI

## Note about Material-UI

Next packages installed as material-ui requirements, they shouldn't be used in main app ui, only in preview of mui theme:

```bash
npm install @mui/material @emotion/react @emotion/styled
```
